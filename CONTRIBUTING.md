# Contributing to Django Todo

Hi there! We're thrilled that you'd like to contribute to our project. 

## First Steps

1. **Fork**: Start by forking the main repository to create a copy under your account
2. **Clone**: Clone your forked repository to your local machine
3. **Branch**: Create a new branch for your feature: `git checkout -b amazing-feature`

## Development Environment

```bash
# Create a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install requirements
pip install -r requirements.txt

# Run the development server
python manage.py runserver


📃Coding Guidelines
Write clean code: We appreciate well-structured and readable code!

Add comments: But not too many! We trust you know what you're doing

Write tests: Please make sure to add tests for your changes. Run existing tests with python manage.py test


Submitting Changes
1-Commit: Use clear and descriptive commit messages
2-Push: Push to your forked repository
3-Open a PR: Submit a Pull Request to the main repository


If You Get Lost...
You can open an issue for questions
Or reach out to us for guidance
Or take a coffee break and try again later!

🧠Remember: Participation matters most, we're here to learn and build together!
